# What's new

Each version of Aipim that has shipped, newest first, in a few lines. Every change, file by file, is in the [CHANGELOG](https://github.com/talis-galhardi/aipim/blob/main/CHANGELOG.md). What comes next is on the [Roadmap](./?path=/docs/roadmap--docs) page.

A component in beta can still change its markup in a minor version. A stable one changes only in a major version, and the CHANGELOG says how to move.

## 1.0.0 · 2026-10-13

The first stable version, the one to build on.

- **Components:** 17 in HTML and CSS, from the button to the modal. One CSS file each and an optional script, checked with axe, the keyboard, 200% zoom and forced colors in Chromium, WebKit and Firefox.
- **Tokens:** a palette from Brazilian homes (urucum, azulejo blue, cajá) in light and dark, in CSS, JSON, Compose and Swift. The generator refuses a pair of colors that fails contrast.
- **Icons and illustrations:** 63 line icons, and ten illustrations for the states of an interface by Luiz Fukumoto.
- **Figma:** the file is in the Figma Community, in Brazilian Portuguese, with variables in light and dark and the same components as the code.
- **Docs:** this Storybook in Brazilian Portuguese and English, tutorials for designers, developers and AI agents, and the AI files (`AGENTS.md`, `llms.txt`).
- **npm:** the package `aipim-ds`.

## 0.1.0, 0.1.1 and 0.1.2 · 2026-10-05 to 2026-10-07

The token generator, the light and dark themes, the English docs and the licenses. The two patches tested the way the npm package is published, with no change to tokens or components.
