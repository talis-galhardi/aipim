# Aipim Design System

A small, open, Brazilian design system with all the parts in place: foundations, 16 web components, icons, documentation and a token generator that enforces accessibility checks. Made to be customized, and to be used by people and by AI.

*Aipim* is the Brazilian Portuguese word for cassava, the root that is the base of so many meals. A design system is the base of many products.

## Where things live

- **Code and issues:** [github.com/talis-galhardi/aipim](https://github.com/talis-galhardi/aipim). MIT license for the code.
- **Figma file:** [Aipim DS](https://www.figma.com/design/iVcCVMsFIyb73AChmjlytU/Aipim-DS). Variables for light and dark, the 16 components and the documentation pages. CC BY 4.0 for the design files.
- **For AI agents:** [AGENTS.md](https://github.com/talis-galhardi/aipim/blob/main/AGENTS.md), [llms.txt](https://github.com/talis-galhardi/aipim/blob/main/llms.txt) and [llms-full.txt](https://github.com/talis-galhardi/aipim/blob/main/llms-full.txt).

## How to read this Storybook

- **Foundations** are the tokens and the icons: color, typography, space and layout, shape and elevation, motion and touch, and the icon catalog. Swatches, scales and previews are generated from `tokens/tokens.json`, so they always match the code.
- **Atoms, Molecules and Organisms** hold the 16 components, grouped by how much they are made of (atoms are single controls, molecules combine a few, organisms are larger parts of a screen). Each page shows every state, then the spec: when to use it, anatomy, keyboard, ARIA and tokens. Every story links to the same component in Figma.
- **Guides** describes how stakeholders, designers and engineers work together with Aipim.
- The toolbar switches between the **light** and **dark** theme (`data-theme`). The accessibility panel checks each story with axe.

## Use it in your project

The components are plain HTML and CSS. Copy `tokens/build/css/aipim.css` and `components/web/aipim-components.css` (or just the CSS files you need), load the fonts Antonio and Karla, and use the classes: `aipim-button`, `aipim-field`, and so on. The optional `aipim.js` handles dismiss buttons, tabs and the modal polyfill.
