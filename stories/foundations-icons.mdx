## Usage and accessibility

The icon takes the color of the text around it. It is decoration, so it is hidden from screen readers, and a button with only an icon needs an `aria-label`.

```html
<svg class="aipim-icon" aria-hidden="true"><use href="icons/sprite.svg#aipim-close"></use></svg>

<button class="aipim-icon-button" aria-label="Close">
  <svg class="aipim-icon" aria-hidden="true"><use href="icons/sprite.svg#aipim-close"></use></svg>
</button>
```
